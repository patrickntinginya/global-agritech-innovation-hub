# Supabase setup (migrations, seed, first administrator)

See the project README for the full walkthrough. Files:

- `migrations/20261020000001_schema.sql`: tables, constraints, indexes.
- `migrations/20261020000002_functions_triggers.sql`: `is_admin()`, profile creation, author stamping, audit, RPCs.
- `migrations/20261020000003_rls_and_grants.sql`: grants and Row Level Security.
- `seed.sql`: Phase 1 demonstration content (generated by `npm run seed:generate`, marked `is_sample = true`).
- `bootstrap_admin.sql`: the controlled way to create the first administrator.
